# Contributing to `@portaless/templates`

## Developer Certificate of Origin (DCO)

Every commit must include a `Signed-off-by:` trailer (`git commit -s`), certifying
that you have the right to submit the contribution under this repository's license
(`CC0-1.0`) and that any added visual asset is original or properly documented in
`demo/ASSETS-LICENSES.md`.

## Content & Asset Rules

1. All showcase profiles, personas, products, and events must be **fictional** and
   visibly labeled `"Demo content, fictional"`.
2. Never add personal accounts, real-person photographs, affiliate links, external
   `unsplash.com`/`placehold.co` URLs, YouTube embeds, or external form endpoints.
3. Run `npm test` (`npm run verify && npm run smoke:tarball`) before opening a PR.
